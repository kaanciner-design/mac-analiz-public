# Maç Analiz — uygulama verisi

Bu repo, Maç Analiz uygulamasının okuduğu türetilmiş verileri içerir ve her gün otomatik güncellenir.
Oran ya da bahis şirketi bilgisi içermez; yalnızca hesaplanmış olasılıklar, tahminler ve sonuçlar bulunur.

- `bugun.json`: önümüzdeki 48 saatin maçları
- `gecmis.json`: başlamış maçların tahminleri ve sonuçları
- `basari.json`: isabet istatistikleri
